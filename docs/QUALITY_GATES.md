# FrameForge release gates

The user wants an original cinematic 3D animation studio with output surpassing the Claude & Pixel / PIXEL STORIES reference.

Visual: cohesive professional characters, no disconnected blocks, consistent facial rigs, deliberate composition, lighting, materials and background depth.
Performance: gaze, blinking, brows, natural lip-sync, pauses, anticipation, gestures, reaction shots and non-repetitive easing.
Audio: distinct intelligible voices, synchronized timing, appropriate Foley, scene transitions, music ducking, no clipping.
Story: setup, escalation, payoff, readable screen inserts and appropriate shot lengths.
Technical: actual rendered frames at 30 FPS, accurate duration, synchronized H.264/AAC MP4, no broken WebGL or browser-console errors.
Evidence: visually inspect representative frames and compare real reference video. Pass all checks before merging or claiming parity.

Work on feature branches, preserve tag v3.0-stable and provide reproducible render evidence.
