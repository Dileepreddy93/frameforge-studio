STEP 1 · PROMPT 1 · CLAUDE → CHATGPT

Create your characters and world
1. Open Claude and start a new chat.
2. Copy Prompt 1, paste your script into the orange bracket, and send.
3. Claude gives you a character sheet prompt for every character and an environment prompt.

  PROMPT 1 · PASTE INTO CLAUDE

  You are my AI reel art director. Read my script and write image prompts that I will paste into ChatGPT
  to create my characters and the world of my reel.

  MY SCRIPT:
  [PASTE YOUR SCRIPT OR STORY HERE]

  STYLE: [YOUR STYLE, OR KEEP: simple low-poly 3D, PS1 game look, flat-shaded]

  Do this:
  1. List every character in my script. Give each one a NAME in CAPITALS.
  2. For each character, write one CHARACTER SHEET prompt (wide 16:9): front, 3/4, side and back view at
  the same scale, plus 4 face close-ups with the expressions my script needs. Describe face, hair, body,
  clothes and props as simple shapes and colours. Plain dark grey background.
  3. Write one ENVIRONMENT prompt (vertical 9:16) for where the story happens: NO characters, and the top
  25% of the frame left empty for captions. If the story has more than one place, write one prompt per
  place.
  4. Start every prompt with the same style line. If the style is not realistic, add "NOT anime, NOT
  Pixar, NOT realistic".
  5. End every prompt with "No text, no labels, no watermark."
  Put each prompt in its own copy box and tell me what to save each image as (sheet-NAME.png,
  environment.png).

STEP 2 · PROMPT 2 · CLAUDE → CHATGPT → GEMINI OMNI

Get the frame and video prompts
1. Go back to the same Claude chat and upload your character sheets and environment image.
2. Copy Prompt 2, fill in the file names, paste the same script, and send.
3. Claude splits your script into clips and gives 2 prompts for every clip: A = first frame (ChatGPT), B =
   video (Gemini Omni).

  PROMPT 2 · PASTE INTO CLAUDE WITH YOUR IMAGES UPLOADED

  I made my characters and the world in ChatGPT. They are attached: [sheet-NAME1.png, sheet-NAME2.png,
  environment.png]

  MY SCRIPT (the same one as before):
  [PASTE YOUR SCRIPT HERE]

  1. Split my script into clips of about 8 seconds each, with max 2 short spoken lines per clip. Use as
  many clips as my script needs. Show me the list first: clip number, what happens, dialogue.

  2. Look closely at the attached images. Then, for EVERY clip, write two prompts:

  A) FIRST FRAME image prompt for ChatGPT (vertical 9:16). Start with: "Use image 1 for NAME1, image 2 for
  NAME2, image 3 for the environment. Keep their designs and style exactly the same." Repeat the style
  line. Describe the shot and angle, where each character is, their pose and expression, and how the
  background looks at the start of this clip. Keep the top 25% of the frame empty for captions. End with
  "No text, no watermark."

  B) VIDEO prompt for Gemini Omni (the video starts from that first frame). Begin with:
  - a STYLE LOCK: keep the exact style and character designs from the image, and do not morph into another
  style
  - a VOICE LOCK: each character's voice (age, accent, pitch, mood, pace)
  Use the same style lock and voice lock, word for word, in every clip. Then write the camera move, the
  actions, the exact dialogue in quotes, and 2-3 sounds. End with "No music. No subtitles, no on-screen
  text."

  Give them in order (Clip 1 A, Clip 1 B, Clip 2 A, Clip 2 B, ...), each in its own copy box, with the file
  name to save (frame1.png, clip1.mp4, ...).

STEP 3 · PROMPT 3 · CLAUDE CODE

Let Claude Code make the finished reel
1. Put all your clips (clip1.mp4, clip2.mp4, …) in your reel folder.
2. Open the Claude desktop app → Code tab and open that folder.
3. Copy Prompt 3, fill in the folder, and send. If Claude asks to install free tools (ffmpeg, Whisper), say yes.

  PROMPT 3 · PASTE INTO CLAUDE CODE

  My clips are in this folder: [YOUR FOLDER, e.g. C:\MY-REEL]
  They are named in story order: clip1.mp4, clip2.mp4, clip3.mp4 ... Use all of them.

  Edit them into one finished vertical reel for Instagram (9:16, 1080 x 1920).

  CUTS
  1. Transcribe every clip with word timings (use Whisper).
  2. Cut the silence at the start and end of each clip, keep a short beat after the punchline, and join
  the clips in order with tiny audio fades (no clicks).

  CAPTIONS (burned into the video)
  3. Show 1-4 words at a time, timed to the voice.
  4. Each word group pops in with a quick bounce: small, slightly bigger, then normal.
  5. Highlight the word being spoken.
  6. Give each character their own colour: main character white with a yellow highlight, second character
  orange with a white highlight.
  7. Give the punchline a bigger pop and a small wobble.
  8. Use a very bold font (like Segoe UI Black) with a thick dark outline and a soft shadow.
  9. Never cover a face: check where the faces are during every caption, and put the caption in the empty
  space above the head, or below the chin in close-ups. Stay inside Instagram's safe zone (the app covers
  the top 220 px and the bottom 420 px).
  10. Make sure no caption line runs off the screen.

  FINISH
  11. Set loudness to -14 LUFS and export MP4 (H.264 + AAC).
  12. Show me frames from every caption, then save the reel in the same folder as final-reel.mp4.

5 tips that make it work
1. Same Claude chat for prompts 1 and 2. Claude then remembers your characters and style.
2. Image first, video second. Never animate a first frame you don’t like.
3. Upload the same sheets + environment for every first frame, so the characters never change.
4. Keep the style lock and voice lock exactly as Claude wrote them in every video prompt.
5. Listen to every take. Gemini Omni sometimes improvises a funnier line. Keep it.
